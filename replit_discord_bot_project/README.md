Replit Discord Bot + Blockly Command Panel

1. Upload alle bestanden naar een nieuwe Replit (Python).
2. Ga naar Tools -> Secrets en voeg:
   - DISCORD_TOKEN = <je bot token>
   - (optioneel) PREFIX = !
3. Start de Replit.
4. Open de webview (de URL van Replit) om de Blockly GUI te gebruiken.
5. Gebruik UptimeRobot (of vergelijkbaar) om de web-URL elke 5 minuten te pingen voor 24/7 uptime.
